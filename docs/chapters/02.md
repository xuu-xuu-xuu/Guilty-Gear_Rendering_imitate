# 连接贴图、UV与顶点数据

把纹理连错通道，会同时改变明暗、高光和线条。先确认每个输入存的是什么数据，再调整视觉效果。

**基础色示意，不是纹理通道导出** [![基础色示意，不是纹理通道导出](../assets/images/stages/00.png)](../assets/images/stages/00.png)

此组累计效果示意固定姿态，省略角色投影，并调整了构图和4K描边像素宽度；用于认识该层外观，不是单个参数的独立开关对照。

## 准备输入

主图集使用UV0，Detail使用UV1（C#的mesh.uv2），可选镜像坐标使用UV2（mesh.uv3）。四主体材质的`_UseMirroredUV=0`，主UV应用_MainTex的Tiling/Offset。

顶点需要POSITION、NORMAL、COLOR和相应UV。COLOR.R用于AO/明暗控制。`_UseSmoothOutline=1`时，TANGENT.xyz必须预先存放专用的平滑描边法线；标准切线不能直接替代它。

Base/Sss/ILM/Detail/OLM以及区域、分类遮罩的通道、过滤、Wrap、压缩和平台覆盖分别列在[贴图连接表](../reference/texture-imports.md)。

## 操作步骤

1. 在主体材质上连接`_MainTex`（Base）、`_ShadowMap`（Sss）、`_LightMap`（ILM）、`_DetailMap`和`_OutlineMap`（OLM）。Base/Sss/OLM的RGB使用sRGB；ILM/Detail保留线性数据。
2. 为自己的UV准备`_RegionalMask`：R为皮肤、G为白袖。连接`_FourMaterialSpecMask`：RGBA依次为头发、布料、皮肤、金属；关闭sRGB和Alpha Is Transparency，保留Alpha通道。
3. 按逐张导入表设置MipMap、Filter、Wrap和压缩。平台overridden未启用时，不要把该条textureFormat当作生效值。先避免有损压缩破坏窄区域，再观察缩小时的表现。
4. 依次观察Debug1/2/3（Base/Sss/Detail）、4–7（ILM RGBA）、8（顶点R）、9（法线）、22/25（区域/类别）。检查完恢复0。
5. 换模型时重新标定眼睛、胸前衣料和腿部区域。相同贴图分辨率不代表相同UV布局，不能直接复制这些坐标常量。

## 原理与代码位置

Base.RGB是基础色，Sss.RGB是阴面颜色，这里的混合不属于物理次表面散射。Detail通过`base × lerp(1,detail,_DetailIntensity)`乘入基础色。

ILM.R×255用于基础分类，G偏移明暗信号，B提供高光细节，`1-ILM.A`提供内部线覆盖。ILM.A和分类图A都不是透明度，主体输出Alpha=1。OLM.RGB只参与墨色，不提供Alpha线宽。

```hlsl
            struct appdata
            {
                float4 vertex:POSITION; float3 normal:NORMAL;
                float2 uv:TEXCOORD0; float2 uv1:TEXCOORD1; float2 uvMirror:TEXCOORD2;
                float4 color:COLOR;
            };
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:310–319](../reference/code/BridgetToon.shader.md#l310)。

```hlsl
            v2f vert(appdata v)
            {
                v2f o;
                o.pos=UnityObjectToClipPos(v.vertex);
                o.worldPos=mul(unity_ObjectToWorld,v.vertex).xyz;
                o.normal=UnityObjectToWorldNormal(v.normal);
                o.uv.xy=TRANSFORM_TEX(lerp(v.uv,v.uvMirror,step(0.5,_UseMirroredUV)),_MainTex);
                o.uv.zw=v.uv1; o.color=v.color;
                TRANSFER_SHADOW(o);
                return o;
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:327–331](../reference/code/BridgetToon.shader.md#l327)。

```hlsl
                half3 base=tex2D(_MainTex,i.uv.xy).rgb;
                half3 sss=tex2D(_ShadowMap,i.uv.xy).rgb;
                float4 ilm=tex2D(_LightMap,i.uv.xy);
                half3 detail=tex2D(_DetailMap,i.uv.zw).rgb;
                half3 albedo=base*lerp(half3(1,1,1),detail,_DetailIntensity);
```

## 参数怎么调

下表区分Shader默认值与四主体材质设置。Base/Secondary/Flip/Coat对应四种主体材质；同名字段还可能被[MPB或全局输入](../reference/overrides.md)覆盖。完整属性类型和纹理绑定见[参数参考](../reference/parameters.md)。

| 属性 | 类型 | Shader默认 | 材质设置 | 作用 |
|---|---|---|---|---|
| _UseMirroredUV | Float | 0.0 | 0 | 主图集的UV选择；修改前确认UV2已经准备好 |
| _DetailIntensity | Range(0,1) | 0.278 | Base=0.278；Secondary=0.278；Flip=0.278；Coat=0 | 乘法细节强度，先检查UV1再调值 |
| _AOStrength | Range(0,1) | 1.0 | 1 | 顶点R对明暗信号的权重 |
| _UseSmoothOutline | Float | 0.0 | 1 | 是否按专用TANGENT.xyz读取平滑描边法线 |

## 画面判断与排错

如果Debug7能看到线条，最终却出现透明孔洞，应检查是否误用了透明Shader，而不是继续调ILM Alpha。若高光和墨线同时串区，先检查数据纹理的sRGB和压缩。

如果Detail没有变化，检查UV1和强度；CoatExterior的Detail强度为0，本来就不显示该项。若轮廓刺出，先确认TANGENT.xyz的实际语义，不能通过修改骨骼补救。
