# 理解Pass与着色执行顺序

先知道各部分在什么时候写入颜色。调节没有进入最终结果的中间量，是“参数改了却看不出变化”的常见原因。

**漫反射、高光、边缘光与线条的合成示意** [![漫反射、高光、边缘光与线条的合成示意](../assets/images/stages/08.png)](../assets/images/stages/08.png)

此组累计效果示意固定姿态，省略角色投影，并调整了构图和4K描边像素宽度；用于认识该层外观，不是单个参数的独立开关对照。

## 准备输入

主体Shader包含FORWARD、OUTLINE、SHADOWCASTER三个Pass。FORWARD使用Built-in的UnityCG/Lighting/AutoLight输入；OUTLINE为独立反向壳；SHADOWCASTER由Unity阴影阶段调度。

自定义阴影深度图在主不透明绘制前准备。因此实现时先接输入与投影，再在FORWARD中建立明暗和各类着色；文件里Pass的排列不等于逐像素计算顺序。

## 在哪里操作

控制流在自己的Shader副本中阅读，Debug在实际使用的练习材质上切换。用[菜单窗口](../reference/practice.md)保持每个编号直到看完；不要将代码摘录粘贴为新Pass，也不要按章节编号推断执行顺序。

## 操作步骤

1. 在Project选中自己的`BridgetToon.shader`，打开文件并用查找定位`half4 frag`、`Name "FORWARD"`、`Name "OUTLINE"`、`Name "SHADOWCASTER"`。只阅读本章列出的最后写入位置；局部摘录不是可粘贴到文件末尾的新Pass。
2. 对实际练习材质打开Debug窗口，依次Apply 10、16、13、12、31，每次回Game视图观察后再改下一号。10应是基础受光权重，16是最终漫反射，13是最终高光，12是rim，31是内线墨色；不能把这些分量当作连续叠加截图。
3. 以材质的`_CleanShadeEnabled`做覆盖试验：先记下1，设0，保持Debug10观察，再切16。按源码该开关不写回band，10不应因这个开关改变；16的覆盖区可能改变。若10也改变，检查是否同时改了光、姿态或其他输入。该试验尚无独立截图。
4. 恢复CleanShade=1。后续每次“参数没反应”都先定位最后写入者：16追CleanShade/FocusedShade，13追FocusedSpec/ThighLobe，12追ReferenceRim；高编号经窗口设置，不修改_DebugMode的原始Range。
5. 点击`Return to Debug 0`，确认完整颜色和外壳都回来。只切Debug时外轮廓消失是代码行为，不去增加_OutlineWidth。继续08接投影输入，再进入05搭建基础明暗。

## 原理与代码位置

FORWARD内的准确位置如下：

| 顺序 | 计算 | 源码行 |
|---|---|---|
| 1 | 采样、眼区、分类、基础band | 321–401 |
| 2 | 头体区域、侧脸和投脸的基础贡献 | 405–458 |
| 3 | Palette，再由CleanShade重建覆盖区diffuse并纳入Palette | 461–501 |
| 4 | Focused局部漫反射、眼睛漫反射细化 | 507–529 |
| 5 | ambient、基础rim、分类spec、Focused/Thigh高光替换 | 532–609 |
| 6 | ReferenceRim替换，再合成diffuse+ambient+rim+spec | 616–625 |
| 7 | 内部线覆盖、原眼睛白点恢复、Debug/最终输出 | 630–725 |

CleanShade不写回band。FocusedSpec重算受光带，ReferenceRim仍使用基础band的阴面权重。因此10、16、13的明暗范围不必完全相同。ThighLobe先替换focusedSkinShine，再经过FocusedSpec的差值合并进入spec。

- [BridgetToon.shader:321–725](../reference/code/BridgetToon.shader.md#l321)：FORWARD：vert / frag及其计算函数。
- [BridgetToon.shader:729–810](../reference/code/BridgetToon.shader.md#l729)：OUTLINE与SHADOWCASTER：描边及阴影Pass。

局部摘录（需结合完整上下文）：[BridgetToon.shader:495–501](../reference/code/BridgetToon.shader.md#l495)。

```hlsl
                half3 cleanFace=lerp(faceDiffuseDark,albedo,cleanFaceBand)*lerp(float3(1,1,1),lerp(_PaletteSkinDark.rgb,_PaletteSkinLight.rgb,cleanFaceBand),saturate(_PaletteEnabled));
                half3 cleanSkin=lerp(skinDark,albedo,cleanSkinBand)*lerp(float3(1,1,1),lerp(_PaletteSkinDark.rgb,_PaletteSkinLight.rgb,cleanSkinBand),saturate(_PaletteEnabled));
                half3 cleanSleeve=lerp(sleeveDark,albedo,cleanSleeveBand)*lerp(float3(1,1,1),lerp(_PaletteSleeveDark.rgb,_PaletteSleeveLight.rgb,cleanSleeveBand),saturate(_PaletteEnabled));
                half3 cleanTunic=lerp(cleanClothDark,albedo,cleanTunicBand)*lerp(float3(1,1,1),lerp(_PaletteTunicDark.rgb,_PaletteTunicLight.rgb,cleanTunicBand),saturate(_PaletteEnabled));
                half3 cleanCloth=lerp(cleanClothDark,albedo,cleanClothBand);
                half3 cleanDiffuse=(cleanFace*faceRegionMask+cleanSkin*bodySkinRegion+cleanSleeve*sleeveRegion+cleanTunic*tunicRegion+cleanCloth*cleanOtherCloth)/max(cleanTotal,0.0001)*_LightColor0.rgb*_LightIntensity;
                diffuse=lerp(diffuse,cleanDiffuse,saturate(_CleanShadeEnabled)*cleanCoverage);
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:605–609](../reference/code/BridgetToon.shader.md#l605)。

```hlsl
                float4 focusedClasses=specClass*float4(1,1,1.0-faceRegionMask,1);
                float focusedSpecCoverage=saturate(dot(focusedClasses,float4(1,1,1,1)));
                half3 focusedOldSpec=(shineHair*focusedClasses.r+shineCloth*focusedClasses.g+shineSkin*focusedClasses.b+shineMetal*focusedClasses.a)*_LightColor0.rgb*band;
                half3 focusedNewSpec=(shineHair*_FocusedHairGain*focusedClasses.r+shineCloth*_FocusedClothGain*focusedClasses.g+focusedSkinShine*focusedClasses.b+shineMetal*_FocusedMetalGain*focusedClasses.a)*_LightColor0.rgb*focusedSpecBand;
                spec+=(focusedNewSpec-focusedOldSpec)*saturate(_FocusedSpecEnabled);
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:620–625](../reference/code/BridgetToon.shader.md#l620)。

```hlsl
                half3 referenceRimColor=lerp(albedo,_ReferenceRimTint.rgb,_ReferenceRimTintMix);
                float referenceRimLight=lerp(_ReferenceRimShadowFloor,1.0,saturate(band));
                half3 referenceRim=referenceRimColor*referenceRimEdge*_ReferenceRimStrength*rimMaterialScale*referenceRimLight*_LightColor0.rgb;
                rim=lerp(rim,referenceRim,saturate(_ReferenceRimEnabled)*specCoverage);
// END GGST RIM REFINE calculations
                half3 color=diffuse+ambient+rim+spec;
```

## 参数怎么调

下表区分Shader默认值与四主体材质设置。Base/Secondary/Flip/Coat对应四种主体材质；同名字段还可能被[MPB或全局输入](../reference/overrides.md)覆盖。完整属性类型和纹理绑定见[参数参考](../reference/parameters.md)。

| 属性 | Inspector名称 | 类型 | Shader默认 | 材质设置 | 作用 |
|---|---|---|---|---|---|
| _CleanShadeEnabled | 角色简洁漫反射明暗 | Range(0,1) | 0.0 | 1 | 覆盖区重建漫反射 |
| _FocusedShadeEnabled | 腹部与腿部阴面收窄 | Range(0,1) | 0.0 | 1 | 修正腿与胸前衣料漫反射 |
| _FocusedSpecEnabled | 整理后独立材质高光 | Range(0,1) | 0.0 | 1 | 决定局部分类高光的最终合并 |
| _ThighLobeEnabled | 大腿局部收尖高光 | Range(0,1) | 0.0 | 1 | 只在满足域与分类门控时替换腿部高光 |
| _ReferenceRimEnabled | 参考风格边缘光启用 | Range(0,1) | 0.0 | 1 | 分类区使用ReferenceRim |
| _DebugMode | 调试输出 0～24（编号见修改文档） | Range(0,24) | 0.0 | 0 | 0为最终输出；高编号通过代码设置 |

## 画面判断与排错

若Debug10看起来正确而16不同，先看CleanShade和FocusedShade；26–29有亮斑而13不同，要看FocusedSpec/ThighLobe；调整_RimWidth无效时，先确认分类区是否使用ReferenceRim。

_DebugMode面板范围是0–24，代码实际支持1–44。设置高编号时使用材质或MPB的SetFloat调用，检查完恢复0；例如设置44只是查看域，不表示大腿开关已生效。19/20展示的变量没有接入最终颜色，不适合判断成图。
