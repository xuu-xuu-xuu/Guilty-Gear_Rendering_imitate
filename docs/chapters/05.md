# 建立两段式明暗

连续的Lambert明暗容易把模型的小凹凸都变成碎影。先压成两块清楚的亮面与阴面，只在边界保留窄过渡。

两图是累计效果示意：姿态相同，但不代表只改变阈值；图中未包含角色投影。

## 准备输入

输入是世界法线、主光方向、Base、Sss、ILM.G及COLOR.R。基础皮肤分类还使用ILM.R。先连接[投影输入](08.md)，再区分表面受光和接收阴影。

_LowerLightDynamic=1时下半身光向会混回当前主光；不要只看_LowerLightDirection保存向量就以为有一盏固定补光灯。

## 操作步骤

1. 先用Debug1、5、8分别检查基础色、ILM.G、顶点R。制作单独练习材质，隔离基础两段式时明确关闭哪些后续重建分支。
2. 固定主光，使用Debug10观察band。先把_LightTreshold设为0.5，增大它应减少亮面；恢复后再调整_RampOffset。
3. 单独调整_RampMaskStrength，观察分界是否跟随ILM.G改变。再调整_AOStrength，确认顶点R对信号的作用。
4. 从_ShadowSoftness=0.008开始控制边缘。先保持窄边界，不要用宽渐变掩盖区域遮罩错误。
5. 恢复CleanShade等目标开关，使用Debug16看最终漫反射，再回0判断完整画面。

## 原理与代码位置

半兰伯特信号为`nl=dot(n,l)*0.5+0.5`，n和l是单位世界方向。它将[-1,1]映射到[0,1]，只是美术受光信号。

公式解释（不是可直接编译的源码；省略下半身光向混合、投影和后续分区）：

```text
ao = lerp(1, saturate(vertex.r), _AOStrength)
signal = (nl + _RampOffset + (ILM.G-_RampMaskCenter)*_RampMaskStrength
          + skin*_SkinShadowOffset) * ao
band = smoothstep(_LightTreshold-soft, _LightTreshold+soft, signal)
```

基础阴色为`lerp(albedo,Sss*_ShadowTint,_ShadowIntensity)`，再按band混合亮暗。G是信号偏移，不是简单乘到最终颜色上的AO。后续分区可能重建漫反射，基础band仍会被部分高光、rim和诊断读取。

- [BridgetToon.shader:365–401](../reference/code/BridgetToon.shader.md#l365)：FORWARD：vert / frag及其计算函数。
- [BridgetToon.shader:405–437](../reference/code/BridgetToon.shader.md#l405)：FORWARD：vert / frag及其计算函数。

局部摘录（需结合完整上下文）：[BridgetToon.shader:386–401](../reference/code/BridgetToon.shader.md#l386)。

```hlsl
                float3 lowerLight=normalize(_LowerLightDirection.xyz+float3(0,0.00001,0));
                lowerLight=normalize(lerp(lowerLight,l,saturate(_LowerLightDynamic)));
                l=normalize(lerp(l,lowerLight,saturate(_LowerLightBlend*lowerRegion)));
                nl=dot(n,l)*0.5+0.5;
                // These are configurable reconstruction hypotheses, not the original GPU equations.
                float ao=lerp(1.0,saturate(i.color.r),_AOStrength);
                float signal=(nl+_RampOffset+(ilm.g-_RampMaskCenter)*_RampMaskStrength+skin*_SkinShadowOffset)*ao;
                float soft=max(_ShadowSoftness,0.00001);
                float band=smoothstep(_LightTreshold-soft,_LightTreshold+soft,signal);
                float rawShadow=SHADOW_ATTENUATION(i);
                float projected=lerp(1.0,rawShadow,_ReceiveShadowStrength);
                band*=projected;
                half3 dark=lerp(albedo,sss*_ShadowTint.rgb,_ShadowIntensity);
                // Reconstructed regional second shade; not the stripped native shader expression.
                float secondShade=lowerRegion*(1.0-band)*(1.0-smoothstep(_SecondShadowThreshold-0.06,_SecondShadowThreshold+0.06,dot(n,l)));
                dark*=lerp(half3(1,1,1),_SecondShadowTint.rgb,secondShade*_SecondShadowStrength);
```

## 参数怎么调

下表区分Shader默认值与四主体材质设置。Base/Secondary/Flip/Coat对应四种主体材质；同名字段还可能被[MPB或全局输入](../reference/overrides.md)覆盖。完整属性类型和纹理绑定见[参数参考](../reference/parameters.md)。

| 属性 | 类型 | Shader默认 | 材质设置 | 作用 |
|---|---|---|---|---|
| _LightTreshold | Range(0,1) | 0.5 | Base=0.5；Secondary=0.5；Flip=0.624；Coat=0.5 | 越高越难进入亮面，保留源码拼写 |
| _RampOffset | Range(-1,1) | 0.0 | 0 | 整体平移受光信号 |
| _RampMaskCenter | Range(0,1) | 0.4980392 | 0.49803922 | ILM.G的偏移中心 |
| _RampMaskStrength | Range(0,2) | 1.0 | 1 | G通道对分界的影响 |
| _ShadowSoftness | Range(0,0.1) | 0.008 | 0.008 | 基础分界的过渡宽度 |
| _ShadowIntensity | Range(0,1) | 0.65 | 0.65 | 基础阴色向Sss混合的权重 |
| _SkinShadowOffset | Range(-0.5,0.5) | 0.06 | 0.06 | 基础皮肤分类的信号偏移 |
| _AOStrength | Range(0,1) | 1.0 | 1 | 顶点R权重 |

## 画面判断与排错

图示基础色与两段式属于累计效果示意，不是仅修改_LightTreshold的独立A/B。复现时应自己固定其他开关，观察阈值带来的局部变化。

碎影跟着纹理走：查G和顶点R。碎影随视角改变：查世界法线、背面翻转。10改变而16没变：查后续重建，而不是继续拉高基础阈值。
