# 塑造大腿局部亮块

给大腿一块范围稳定、下端收尖的局部亮形，同时清除周围不需要的散光。形状由当前图集坐标定义，可见度再受光向与视向控制。

| 对照 | 对照 |
|---|---|
| **ThighLobe关闭** [![ThighLobe关闭](../assets/images/project/thigh_before.png)](../assets/images/project/thigh_before.png) | **ThighLobe开启** [![ThighLobe开启](../assets/images/project/thigh_after.png)](../assets/images/project/thigh_after.png) |

同条件的局部高光开关对照；颜色是最终合成结果，不等于Tint参数本身。

## 准备输入

需要分类图B的皮肤、身体皮肤域、head=0、世界法线/视线/光向，以及当前2048图集的腿UV。_FocusedSpecEnabled必须接入最终高光合并。

换UV时要重新设计腿域、中心曲线、宽度、纵向窗口和膝盖过渡。普通点高光的宽度参数不能替代这些空间定义，也不要改骨骼或Bind Pose迁就图集常量。

## 操作步骤

1. 先用22确认身体皮肤、25确认皮肤类别，再用40看目标腿域。
2. 用43看替换域，44看亮形×朝向。它们没有乘_ThighLobeEnabled，所以非黑不能证明最终开关打开。
3. 固定姿态和FocusedSpec=1，在_ThighLobeEnabled=0/1之间比较Debug13及最终0。先判断亮块是否在正确表面，替换域是否越过膝盖。
4. 形状正确后，从Strength=0.16和Tint=(0.92,1,0.45,1)开始调整，保持光照和Palette不动。
5. 播放已有站立循环，逐姿态确认亮块范围与下端，异常时暂停回到13/43/44排查。

## 原理与代码位置

坐标为`p=(u*2048,(1-v)*2048)`，腿域x200…510、y880…1195。前侧中心从357.89起分段修正，在y约981处改变走向；完整系数见局部源码，不能概括为任意UV上的直竖条。

收尖使用`t=saturate((p.y-918)/82)`和`halfWidth=7.2*(1-pow(t,1.15))`。fwidth平滑横向边缘，纵向窗口约916–1001；朝向门控为`smoothstep(0.2,0.55,nv)*smoothstep(0.50,0.68,nl)`，nl是半兰伯特。

替换域比亮形更宽，在y1015–1030前收掉。域内即使lobe=0，也会替换掉基础腿部高光。ThighLobe先替换focusedSkinShine，再由FocusedSpec合并到spec，所以它不是完全独立的最终高光层。

- [BridgetToon.shader:507–518](../reference/code/BridgetToon.shader.md#l507)：FORWARD：vert / frag及其计算函数。
- [BridgetToon.shader:580–609](../reference/code/BridgetToon.shader.md#l580)：FORWARD：vert / frag及其计算函数。

局部摘录（需结合完整上下文）：[BridgetToon.shader:583–603](../reference/code/BridgetToon.shader.md#l583)。

```hlsl
                float thighT=saturate((palettePixel.y-918.0)/82.0);
                // Follow the measured anterior meridian of the original UV island;
                // its ring spacing bends at y=981, so a straight UV line is not
                // a straight line on the existing thigh surface.
                float thighCenter=357.89;
                thighCenter+=(-0.44)*saturate((palettePixel.y-916.85)/11.84);
                thighCenter+=(-1.35)*saturate((palettePixel.y-928.69)/12.07);
                thighCenter+=(-1.70)*saturate((palettePixel.y-940.76)/13.24);
                thighCenter+=(-1.90)*saturate((palettePixel.y-954.0)/13.74);
                thighCenter+=(4.90)*saturate((palettePixel.y-967.74)/13.89);
                thighCenter+=(-1.30)*saturate((palettePixel.y-981.63)/9.42);
                thighCenter+=(-1.24)*saturate((palettePixel.y-991.05)/9.62);
                float thighHalfWidth=7.2*(1.0-pow(thighT,1.15));
                float thighEdge=thighHalfWidth-abs(palettePixel.x-thighCenter);
                float thighAA=max(fwidth(thighEdge)*0.65,0.35);
                float thighLobe=smoothstep(-thighAA,thighAA,thighEdge);
                thighLobe*=smoothstep(916.0,920.0,palettePixel.y)*(1.0-smoothstep(998.0,1001.0,palettePixel.y));
                float thighReplace=focusedLegDomain*(1.0-head)*(1.0-smoothstep(1015.0,1030.0,palettePixel.y));
                float thighFacing=smoothstep(0.2,0.55,nv)*smoothstep(0.50,0.68,nl);
                half3 thighShine=_ThighLobeTint.rgb*_ThighLobeStrength*thighLobe*thighFacing;
                focusedSkinShine=lerp(focusedSkinShine,thighShine,thighReplace*saturate(_ThighLobeEnabled));
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:605–609](../reference/code/BridgetToon.shader.md#l605)。

```hlsl
                float4 focusedClasses=specClass*float4(1,1,1.0-faceRegionMask,1);
                float focusedSpecCoverage=saturate(dot(focusedClasses,float4(1,1,1,1)));
                half3 focusedOldSpec=(shineHair*focusedClasses.r+shineCloth*focusedClasses.g+shineSkin*focusedClasses.b+shineMetal*focusedClasses.a)*_LightColor0.rgb*band;
                half3 focusedNewSpec=(shineHair*_FocusedHairGain*focusedClasses.r+shineCloth*_FocusedClothGain*focusedClasses.g+focusedSkinShine*focusedClasses.b+shineMetal*_FocusedMetalGain*focusedClasses.a)*_LightColor0.rgb*focusedSpecBand;
                spec+=(focusedNewSpec-focusedOldSpec)*saturate(_FocusedSpecEnabled);
```

## 参数怎么调

下表区分Shader默认值与四主体材质设置。Base/Secondary/Flip/Coat对应四种主体材质；同名字段还可能被[MPB或全局输入](../reference/overrides.md)覆盖。完整属性类型和纹理绑定见[参数参考](../reference/parameters.md)。

| 属性 | 类型 | Shader默认 | 材质设置 | 作用 |
|---|---|---|---|---|
| _ThighLobeEnabled | Range(0,1) | 0.0 | 1 | 控制腿部局部替换 |
| _ThighLobeStrength | Range(0,0.4) | 0.16 | 0.16 | 局部亮块强度 |
| _ThighLobeTint | Color | [0.92, 1.0, 0.45, 1.0] | (0.92, 1, 0.45, 1) | 亮块颜色输入，不是最终屏幕颜色 |
| _FocusedSpecEnabled | Range(0,1) | 0.0 | 1 | 大腿结果合并进入最终spec的依赖 |
| _FocusedSkinStrength | Range(0,0.4) | 0.14 | 0.14 | 替换域之外的Focused皮肤高光 |
| _FocusedSkinWidth | Range(0.02,0.4) | 0.22 | 0.22 | Focused皮肤亮带宽度 |

## 画面判断与排错

44有形而13没有：查开关、FocusedSpec、皮肤分类、head及受光带。整腿变色：查替换域范围。亮形扭曲：查UV和中心曲线。

示例OFF/ON图是同条件的ThighLobe开关对照；Debug44只显示域与朝向。Tint是Color参数，屏幕亮块还受光色、受光带和显示转换影响，不应直接按Tint数值取色。
