# 细化眼睛与原有白点

给虹膜增加上暗下亮的层次，保护黑瞳、眼线和原有白点。变化要局限于眼区，避免把整张脸提亮成贴纸。

| 对照 | 对照 |
|---|---|
| **眼睛细化关闭** [![眼睛细化关闭](../assets/images/experiments/20261021/eye_off_crop.png)](../assets/images/experiments/20261021/eye_off_0.png) | **眼睛细化开启** [![眼睛细化开启](../assets/images/experiments/20261021/eye_on_crop.png)](../assets/images/experiments/20261021/eye_on_0.png) |

同姿态、同取景、Debug0原图的相同矩形裁切；1600×900、HDR关闭、RT单采样。只改头Renderer的_EyeRefineEnabled，点击查看完整近景。

## 准备输入

输入是主图集Base、主UV、head标志、主光和band，不需要新增眼睛纹理。_EyeRefineEnabled在Base/Secondary为1，Flip/Coat为0，还需要_RegionalHead=1。

区域是当前2048图集专用：小虹膜中心(960,64)、半径(34,34)，大虹膜中心(1152,130)、半径(104,100)。眼白域在x896…1280/y0…256，并结合接近(0.8388,0.8308,0.9301)的颜色选择。换图集要重新标定虹膜、瞳孔、眼白、原白点及颜色门控。

## 在哪里操作

在站立头的Base/Secondary练习材质上改眼睛参数；先用来源查询确认该Renderer的head MPB为1。相机近景只在进入对照前调整一次，开关比较期间不再改构图。

## 操作步骤

1. 在Hierarchy选站立头，确认所用Base/Secondary练习材质及`_RegionalHead=1`的MPB；在Debug窗口把该材质设33。预期R是虹膜、G是眼白、B是原白点，兜帽和普通脸皮肤不应成为眼区。区域不对时先改自己的图集坐标，不开始调亮度。
2. 暂停固定姿态，保持同一Camera近景与输出设置。在材质“眼睛分区层次启用”`_EyeRefineEnabled`做0→1，并在Debug0截图比较；再单独切34查贡献后回0。现有同条件裁切只支持该总开关对照，不证明下面每个子参数的独立效果已经实测。
3. 保持Enabled=1，先把“虹膜上层深色”_EyeIrisUpperDepth从0.18设0再恢复，预期取消上部暗化；再把“虹膜下层透亮”_EyeIrisLowerLift从0.1设0再恢复，预期取消受光下部提亮。两次分开做，黑瞳和眼线不应整体变亮；band为0时下部加亮可能本来不可见。
4. 单独将_EyeIrisEdgeDepth从0.08设0再恢复，检查虹膜边缘暗化；再单独将_EyeScleraShade从0.06设0再恢复，检查眼白轻微冷暗变化。当前姿态或分辨率可能让差异很小，不能把34的显示亮度当作最终画面增亮量。
5. 单独将_EyeCatchlightLift从0.25设0再恢复，只比较原白点，不期待生成新运动光点。保留HeadGlow/HeadDecal槽，白点也可能受贴图和辅助层影响。上述子参数归零试验依据源码，尚未在Unity逐个验证。
6. 全部恢复本章保存值并回0，按14播放已有站立循环，在眼形、朝向变化处暂停检查。换UV时按02先重标定虹膜/瞳孔保护/眼白/原白点与颜色门控；同分辨率的新贴图不能直接复用旧坐标。

## 原理与代码位置

EyeDisk通过长度阈值和fwidth形成平滑椭圆；`min(base.g,base.b)-base.r`选择青色虹膜，结合瞳孔保护，避免把黑瞳、眼线和白点一起提升。

漫反射先压暗上部和外缘，再根据原albedo与band提亮下部。内部线合成后，代码恢复已有白高光，不生成运动点。原小眼白点中心为(938.7075,48.0896)/(983.5789,85.5)，这不是通用眼睛定位方法。

如果MPB没有Eye开关覆盖，应读取材质值；对不存在的MPB字段调用GetFloat得到0，不能据此认定眼睛关闭。

局部摘录（需结合完整上下文）：[BridgetToon.shader:337–353](../reference/code/BridgetToon.shader.md#l337)。

```hlsl
                float2 eyePixel=float2(i.uv.x*2048.0,(1.0-i.uv.y)*2048.0);
                float eyeHead=saturate(_EyeRefineEnabled)*saturate(_RegionalHead);
                float2 eyeSmallQ=(eyePixel-float2(960.0,64.0))/float2(34.0,34.0);
                float2 eyeLargeQ=(eyePixel-float2(1152.0,130.0))/float2(104.0,100.0);
                float eyeSmallDisk=EyeDisk(eyeSmallQ);
                float eyeLargeDisk=EyeDisk(eyeLargeQ);
                float eyeSmallPupil=smoothstep(1.10,1.24,length((eyePixel-float2(960.0,64.0))/float2(13.0,13.0)));
                float eyeLargePupil=smoothstep(1.10,1.24,length((eyePixel-float2(1152.0,129.0))/float2(29.0,35.0)));
                // Bounded original teal chroma protects black pupils/ink and
                // authored white glints, including compressed texture edges.
                float eyeChroma=smoothstep(0.015,0.055,min(base.g,base.b)-base.r);
                float eyeIrisMask=saturate(eyeSmallDisk+eyeLargeDisk)*eyeSmallPupil*eyeLargePupil*eyeChroma*eyeHead;
                float2 eyeQ=lerp(eyeSmallQ,eyeLargeQ,step(1020.0,eyePixel.x));
                float eyeUp=-eyeQ.y; // PNG y increases downwards.
                float eyeUpper=smoothstep(-0.20,0.55,eyeUp);
                float eyeLower=(1.0-smoothstep(-0.35,0.40,eyeUp))*(1.0-smoothstep(0.75,1.0,length(eyeQ)));
                float eyeEdge=smoothstep(0.56,0.94,length(eyeQ));
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:361–362](../reference/code/BridgetToon.shader.md#l361)。

```hlsl
                float eyeCatchMask=eyeAuthoredGlint*smoothstep(0.85,0.97,min(base.r,min(base.g,base.b)))*eyeHead;
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:521–529](../reference/code/BridgetToon.shader.md#l521)。

```hlsl
// BEGIN GGST EYE REFINEMENT diffuse layers
                half3 eyeBeforeDiffuse=diffuse;
                float eyeDepth=saturate(_EyeIrisUpperDepth*eyeUpper+_EyeIrisEdgeDepth*eyeEdge);
                diffuse*=1.0-eyeIrisMask*eyeDepth;
                // Reuse the original iris hue and the same lit/shadow band.
                // No emission or time-driven sparkle is introduced.
                diffuse+=albedo*half3(0.70,1.0,0.92)*_LightColor0.rgb*_LightIntensity*band*eyeIrisMask*eyeLower*_EyeIrisLowerLift;
                diffuse*=lerp(half3(1,1,1),half3(0.70,0.85,1.0),eyeScleraMask*_EyeScleraShade);
                half3 eyeDiffuseDelta=diffuse-eyeBeforeDiffuse;
```

## 参数怎么调

下表区分Shader默认值与四主体材质设置。Base/Secondary/Flip/Coat对应四种主体材质；同名字段还可能被[MPB或全局输入](../reference/overrides.md)覆盖。完整属性类型和纹理绑定见[参数参考](../reference/parameters.md)。

| 属性 | Inspector名称 | 类型 | Shader默认 | 材质设置 | 作用 |
|---|---|---|---|---|---|
| _EyeRefineEnabled | 眼睛分区层次启用 | Range(0,1) | 0.0 | Base=1；Secondary=1；Flip=0；Coat=0 | 启用眼睛细化，还需head门控 |
| _EyeIrisUpperDepth | 虹膜上层深色 | Range(0,0.5) | 0.18 | 0.18 | 虹膜上部暗化 |
| _EyeIrisLowerLift | 虹膜下层透亮 | Range(0,0.4) | 0.1 | 0.1 | 虹膜下部提亮 |
| _EyeIrisEdgeDepth | 虹膜外缘层次 | Range(0,0.3) | 0.08 | 0.08 | 虹膜边缘深度感 |
| _EyeCatchlightLift | 原白色高光清晰度 | Range(0,0.5) | 0.25 | 0.25 | 恢复原白点清晰度 |
| _EyeScleraShade | 眼白克制冷色 | Range(0,0.2) | 0.06 | 0.06 | 眼白轻微压暗 |
| _RegionalHead | 头部 Renderer 分区（隐藏；连接层写入） | Float | 0.0 | 0 | 头Renderer由MPB写1 |

## 画面判断与排错

瞳孔变亮：检查色度与瞳孔保护域。整脸被改色：先检查head和UV域。34很亮但0变化轻微：诊断表达式和显示颜色不同，不要继续盲目提高强度。

近景开关图来自同姿态、相同取景的Debug0图，以相同矩形[744,316,955,439]裁切为211×123，只裁切不修饰。更完整的操作对照见[投影与眼睛调试](../reference/experiments-20261021.md)。
