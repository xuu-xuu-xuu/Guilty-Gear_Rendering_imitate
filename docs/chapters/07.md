# 调整亮面与阴面配色

明暗边界合适以后，再调亮面和阴面的色调。这样可以修正皮肤偏脏、袖子偏黄等问题，而不破坏已经整理好的明暗形状。

**区域配色示意** [![区域配色示意](../assets/images/stages/03.png)](../assets/images/stages/03.png)

此组累计效果示意固定姿态，省略角色投影，并调整了构图和4K描边像素宽度；用于认识该层外观，不是单个参数的独立开关对照。

## 准备输入

Palette依赖皮肤/白袖遮罩、head标志、胸前UV域和各自band。输入仍是Base与Sss；Palette不是贴图替代。

六个_Palette*Light/Dark在Shader中是Vector，公式使用rgb，第四分量为0。它们是计算乘数，不是屏幕最终颜色，也不具有Color属性相同的颜色输入语义。

## 操作步骤

1. 固定CleanShade/Focused和主光，用Debug37确认皮肤、白袖和胸前衣料范围。
2. 输出16，在_PaletteEnabled=0/1之间比较同姿态。先确认改变的是色调，不是区域位置。
3. 分别调整一个区域的Light或Dark向量。先观察该区域的亮面与阴面，再回0看整体。
4. 如果只想改变皮肤，不要调全局灯色；如果向量影响了头发，先修区域门控。
5. 换UV后重新定位胸前区域，再重复局部调色。

## 原理与代码位置

单一区域内可用`M=lerp(M_dark,M_light,band)`理解配色，漫反射再乘M。这个数学解释省略了区域混合、CleanShade重建和光照，不是完整实现。

皮肤亮面乘数(0.92,1.1,1.28)降低R相对比例，阴面乘数(0.82,0.7,0.82)与已有阴色相乘。不能仅看向量就给出最终sRGB取色。

Palette只作用于diffuse。CleanShade重建时会重新纳入相同乘数，不应在合成外再乘一次。ambient、spec、rim和墨线有独立路径。

- [BridgetToon.shader:461–501](../reference/code/BridgetToon.shader.md#l461)：FORWARD：vert / frag及其计算函数。
- [BridgetToon.shader:516–518](../reference/code/BridgetToon.shader.md#l516)：FORWARD：vert / frag及其计算函数。

局部摘录（需结合完整上下文）：[BridgetToon.shader:469–476](../reference/code/BridgetToon.shader.md#l469)。

```hlsl
                float paletteSkinBand=lerp(saturate(skinBand*projected),saturate(lerp(faceBand,faceDiffuseBand,saturate(_FaceDiffuseRefine))*projected),head);
                float3 paletteSkinMultiplier=lerp(_PaletteSkinDark.rgb,_PaletteSkinLight.rgb,paletteSkinBand);
                float3 paletteSleeveMultiplier=lerp(_PaletteSleeveDark.rgb,_PaletteSleeveLight.rgb,saturate(sleeveBand*projected));
                float3 paletteTunicMultiplier=lerp(_PaletteTunicDark.rgb,_PaletteTunicLight.rgb,saturate(band));
                float3 paletteMultiplier=1.0+(paletteSkinMultiplier-1.0)*paletteSkin+(paletteSleeveMultiplier-1.0)*sleeveRegion+(paletteTunicMultiplier-1.0)*tunicRegion;
                float3 paletteGate=float3(paletteSkin,sleeveRegion,tunicRegion);
                // Do not recolor albedo, band, ambient, specular, rim or ink.
                diffuse*=lerp(float3(1,1,1),paletteMultiplier,saturate(_PaletteEnabled));
```

局部摘录（需结合完整上下文）：[BridgetToon.shader:494–501](../reference/code/BridgetToon.shader.md#l494)。

```hlsl
                half3 cleanClothDark=lerp(albedo,sss*_ShadowTint.rgb,_ShadowIntensity);
                half3 cleanFace=lerp(faceDiffuseDark,albedo,cleanFaceBand)*lerp(float3(1,1,1),lerp(_PaletteSkinDark.rgb,_PaletteSkinLight.rgb,cleanFaceBand),saturate(_PaletteEnabled));
                half3 cleanSkin=lerp(skinDark,albedo,cleanSkinBand)*lerp(float3(1,1,1),lerp(_PaletteSkinDark.rgb,_PaletteSkinLight.rgb,cleanSkinBand),saturate(_PaletteEnabled));
                half3 cleanSleeve=lerp(sleeveDark,albedo,cleanSleeveBand)*lerp(float3(1,1,1),lerp(_PaletteSleeveDark.rgb,_PaletteSleeveLight.rgb,cleanSleeveBand),saturate(_PaletteEnabled));
                half3 cleanTunic=lerp(cleanClothDark,albedo,cleanTunicBand)*lerp(float3(1,1,1),lerp(_PaletteTunicDark.rgb,_PaletteTunicLight.rgb,cleanTunicBand),saturate(_PaletteEnabled));
                half3 cleanCloth=lerp(cleanClothDark,albedo,cleanClothBand);
                half3 cleanDiffuse=(cleanFace*faceRegionMask+cleanSkin*bodySkinRegion+cleanSleeve*sleeveRegion+cleanTunic*tunicRegion+cleanCloth*cleanOtherCloth)/max(cleanTotal,0.0001)*_LightColor0.rgb*_LightIntensity;
                diffuse=lerp(diffuse,cleanDiffuse,saturate(_CleanShadeEnabled)*cleanCoverage);
```

## 参数怎么调

下表区分Shader默认值与四主体材质设置。Base/Secondary/Flip/Coat对应四种主体材质；同名字段还可能被[MPB或全局输入](../reference/overrides.md)覆盖。完整属性类型和纹理绑定见[参数参考](../reference/parameters.md)。

| 属性 | 类型 | Shader默认 | 材质设置 | 作用 |
|---|---|---|---|---|
| _PaletteEnabled | Range(0,1) | 0.0 | 1 | 控制区域配色 |
| _PaletteSkinLight | Vector | [0.92, 1.1, 1.28, 0.0] | (0.92, 1.1, 1.28, 0) | 皮肤亮面RGB乘数 |
| _PaletteSkinDark | Vector | [0.82, 0.7, 0.82, 0.0] | (0.82, 0.7, 0.82, 0) | 皮肤阴面RGB乘数 |
| _PaletteSleeveLight | Vector | [0.99, 1.0, 1.07, 0.0] | (0.99, 1, 1.07, 0) | 白袖亮面RGB乘数 |
| _PaletteSleeveDark | Vector | [0.9, 0.93, 1.02, 0.0] | (0.9, 0.93, 1.02, 0) | 白袖阴面RGB乘数 |
| _PaletteTunicLight | Vector | [1.0, 1.08, 1.23, 0.0] | (1, 1.08, 1.23, 0) | 胸前衣料亮面RGB乘数 |
| _PaletteTunicDark | Vector | [1.03, 1.06, 1.19, 0.0] | (1.03, 1.06, 1.19, 0) | 胸前衣料阴面RGB乘数 |

## 画面判断与排错

37显示区域，16显示漫反射，0显示完整合成。16改变而高光颜色没跟着变是正常的分量分工；如果整张图一起偏色，应检查主光、环境和sRGB。

示意图用于观察配色方向，不是六个向量的独立开关对照。调参时保持同一姿态，每次只动一个区域的一组乘数。
