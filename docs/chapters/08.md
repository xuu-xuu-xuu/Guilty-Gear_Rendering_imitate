# 接入投脸与墙地投影

先把三类阴影分开：角色表面受光、头发投脸、角色投到墙和地面。它们使用不同路径，不能用一个“阴影强度”统一解释。

## 准备输入

需要已连接的Player/nativeRendering、实际可见Renderer、只读头/骨盆坐标、同场景主相机与方向光、分类图R作为hairMask，以及GGSTGeometryDepth Shader。缺少原呈现类型时，按[接口说明](../reference/dependencies.md)接入已有对象；没有可用的深度纹理时不能只把全局enable设为1。

GGSTGeometryShadowMaps字段基准为hairRadius=0.28、hairRange=1.2、hairWorldUpOffset=0.08、stageRadius=2、stageRange=8；suspendMaps关闭，两个draw开关打开。头发深度图1024²、Stage深度图2048²，均为RFloat、Point/Clamp、无MipMap、单采样。

## 操作步骤

1. 在GGSTGeometryShadowMaps接入p、mainCamera、lightSource、hairMask和depthShader。先确认Ready、Renderer可见状态、draw count和全局纹理有效，再看影子形状。
2. 为地面、墙面设置GGST/StageShadowReceiver材质。地面floor/bias/filter/fade使用0.08/0.0007/0.65/0.12；墙面使用0.1/0.001/0.8/0.08。floor是最低可见率，不是最终屏幕颜色。
3. 固定姿态，只把一个接收Renderer的_GeometryShadowFloor设为1：该面自定义接收衰减应消失，另一面和角色明暗保留。分别恢复地面0.08、墙面0.1。
4. 单独切drawStageCasters时，要知道enable=0会回退Unity的SHADOW_ATTENUATION，这个对照不等于“全部投影关闭”。
5. 检查投脸时同时观察_FaceFrameValid、脸域、_HairFaceShadowStrength及CleanShade。固定其他分支后再调bias/filter，不要把Debug32直接当最终脸部阴影。

## 原理与代码位置

深度图从光源方向记录最近表面。接收点投到同一VP空间后比较深度，靠后的点受遮挡。Bias减少表面误判自身遮挡，太大则可能让影子悬空；3×3过滤只软化边缘。

脚本在onPreCull记录命令，通过BeforeForwardOpaque使用现有蒙皮Renderer并发布深度图。Stage中心在光空间按texel对齐；错误的更新时机可能造成影子滞后。

接收面可见率为`1-occlusion*(1-floor)`，因此floor=1会取消自定义衰减而保留有效深度路径。角色的_ReceiveShadowStrength只影响基础band；投脸先改变脸diffuse，随后可能被CleanShade覆盖。Base/Secondary的投脸强度为0，不能把它强行调高当作目标效果。

            {
                if(_GGSTShadowCasterHairOnly>0.5)
                    clip(tex2D(_GGSTShadowCasterHairMask,i.uv).r-0.5);
                // Original base alpha is encoded data (gold hair mostly 66/67),
                // and ILM alpha is ink. Neither is used as transparency here.

局部摘录（需结合完整上下文）：[BridgetToon.shader:247–261](../reference/code/BridgetToon.shader.md#l247)。

```hlsl
            float ReadHairVisibility(float3 world)
            {
                float4 clipSpace=mul(_HairShadowVP,float4(world,1));
                float2 uv=clipSpace.xy/max(clipSpace.w,0.00001)*0.5+0.5;
                float depth=dot(world-_HairShadowOriginRange.xyz,_HairShadowForward.xyz)/max(_HairShadowOriginRange.w,0.00001);
                float inside=step(0,uv.x)*step(uv.x,1)*step(0,uv.y)*step(uv.y,1)*step(0,depth)*step(depth,1);
                float bias=_HairFaceShadowBias/max(_HairShadowOriginRange.w,0.00001);
                float visibility=0;
                [unroll] for(int x=-1;x<=1;x++)
                [unroll] for(int y=-1;y<=1;y++)
                {
                    float stored=tex2D(_HairShadowDepth,uv+float2(x,y)*_HairShadowTexel.xy*_HairFaceShadowFilter).r;
                    visibility+=step(depth-bias,stored);
                }
                return lerp(1.0,visibility/9.0,inside*saturate(_HairShadowEnabled));
```

局部摘录（需结合完整上下文）：[StageShadowReceiver.shader:80–88](../reference/code/StageShadowReceiver.shader.md#l80)。

```hlsl
                fixed atten = SHADOW_ATTENUATION(i);
// BEGIN GGST SHADOW REFINEMENT stage independent projection
                if(_StageShadowEnabled>0.5)atten=GeometryStageVisibility(i.worldPos);
// END GGST SHADOW REFINEMENT stage independent projection
                fixed u = saturate(i.pos.x / _ScreenParams.x);

                return fixed4(c, 1);
```

## 参数怎么调

下表区分Shader默认值与四主体材质设置。Base/Secondary/Flip/Coat对应四种主体材质；同名字段还可能被[MPB或全局输入](../reference/overrides.md)覆盖。完整属性类型和纹理绑定见[参数参考](../reference/parameters.md)。

| 属性 | 类型 | Shader默认 | 材质设置 | 作用 |
|---|---|---|---|---|
| _ReceiveShadowStrength | Range(0,1) | 0.7 | 0.7 | 角色基础band接收Unity投影的权重 |
| _HairFaceShadowStrength | Range(0,1) | 0.0 | Base=0；Secondary=0；Flip=0.75；Coat=0.75 | 投脸基础贡献，后面可能被CleanShade替换 |
| _HairFaceShadowBias | Range(0,0.01) | 0.0006 | 0.0006 | 头发深度比较偏移 |
| _HairFaceShadowFilter | Range(0,3) | 1.1 | 1.1 | 头发投影过滤范围 |
| _CleanShadeEnabled | Range(0,1) | 0.0 | 1 | 决定脸部是否被后续漫反射重建覆盖 |

## 画面判断与排错

影子截断先检查radius/range，错位先检查VP和纹理坐标，贴面黑斑查bias，悬空查bias是否过大。若深度图白且draw count为0，先排查Ready与Renderer，不要判为“没有遮挡”。

最终脸部没有投发暗带时，先看当前强度和CleanShade覆盖；Debug32非黑只说明中间遮挡量存在。墙/地对照图及具体复现步骤见[投影与眼睛调试](../reference/experiments-20261021.md)。
