# 如何阅读对照图

先看图注中的输出、姿态、取景和画质条件，再判断参数带来的变化。点击图片可以查看原尺寸。

| 图片类型 | 可以怎样用 | 比较时注意 |
|---|---|---|
| 完整角色图 | 认识最终形体、材质与投影关系 | 不能与不同构图的图直接做单变量比较 |
| 累计4K示意 | 认识从基础色到各效果层的外观 | 同姿态，但省略投影、调整构图；外描边像素宽度×2，不是每个参数独立实验 |
| 1600×900投影开关图 | 比较墙或地单个接收属性 | 同姿态、同相机；HDR关闭、相机MSAA关闭、RT单采样 |
| 眼睛开关局部 | 看上暗下亮和原白点的细微变化 | 同条件Debug0原图、同一211×123窗口，只裁切不修饰 |
| 站立逐姿态图 | 看投影、亮块、眼形和轮廓如何随姿态变化 | 同取景但姿态不同，不是Shader开关A/B |
| Debug图 | 只观察对应中间量或最终分量 | 不是完整画面颜色；Debug会隐藏外轮廓 |

累计示意的相邻层可能同时带入一组效果，不能用于量化某个单独旋钮。腹部/腿部综合配色图还同时改变过阴影与高光，不用于纯阴影归因。

[投影与眼睛调试](experiments-20261021.md)给出可以直接照做的开关步骤；[站立画面排查](standing-stability-20261021.md)保留对应姿态与近景。纹理通道请在自己的材质中用Debug查看，基础色截图不是原始贴图导出。
