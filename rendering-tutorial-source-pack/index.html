01_inventory

资料清单

A. 9 份当前工程渲染源码：6 个 Shader + 3 个 C# 脚本
核心：
  sources/BridgetToon.shader：主体漫反射、材质高光、边缘光、内部线、外轮廓、ShadowCaster。
  sources/StageShadowReceiver.shader：背景/地面梯度与投影接收。
  sources/GGSTGeometryDepth.shader：离屏头发/角色深度图。
  sources/GGSTRegionalShading.cs：Renderer 分区与只读脸部坐标 MPB。
  sources/GGSTGeometryShadowMaps.cs：原有 Renderer 离屏绘制、投影矩阵、全局阴影参数。
  sources/BridgetImitateProfile.cs：角色原点/身高 MPB 和质量设置。
辅助：
  sources/GgstDecal.shader：X2 Multiply 贴花。
  sources/GgstGlow.shader：基础色发光输出。
  sources/GgstShadowParked.shader：禁用旧辅助阴影几何的绘制。
辅助材质保留在资料中用于解释材质槽，不代表站立最终画面都在使用这些槽。
原文、源码行数、来源相对路径、SHA256：data/source_index.csv。

B. 实际参数与环境
  data/materials_saved.json：12 个材质完整保存参数，含历史冗余字段及纹理引用。
  data/material_parameters.csv：793 行“材质 × Shader 声明属性”记录，区分默认值、保存值、脚本覆盖。
  data/shader_properties.csv：165 项 Shader 属性声明（跨 6 个 Shader 合计）、类型、默认值与源码行号。
  data/runtime_overrides.csv：6 类覆盖规则；动态值不能冒充常数。
  data/runtime_write_sites.csv：3 个渲染脚本中的具体写入行。
  data/saved_scene_rendering.json：已保存主场景的相机、灯光、渲染组件、Renderer 材质槽及 Prefab 材质覆盖。
  data/environment.json：Unity 版本、Built-in 相关配置、Linear、质量设置与包依赖；包依赖不等于全部必须安装。
  data/debug_outputs.csv：44 个 Debug 输出的真实表达式与行号。

C. 贴图接口说明（没有贴图文件）

  data/texture_import_settings.json：11 张被引用贴图的尺寸、sRGB、采样、MipMap、平台覆盖等。
  notes/03_texture_channels.txt：通道语义、UV、Alpha 与色彩空间注意点。

D. 21 张真实渲染图

03_texture_channels

贴图与顶点输入契约（只描述当前 Shader 的使用方式，不代表已证明原游戏通道定义）

_MainTex / BGT_base：RGB 基础色；sRGB=1。主体 Opaque 输出，不把 A 当透明度。
_ShadowMap / BGT_Sss：RGB 阴面颜色；sRGB=1。当前用途是颜色混合，不是物理次表面散射。
_LightMap / BGT_ilm：sRGB=0。
  R：乘 255 后参与旧材质分类；与衣料/皮肤有混杂，最终精修使用单独分类遮罩。
  G：明暗信号偏移，以 _RampMaskCenter 为中性点，不是直接乘整张图的通用 AO。
  B：原有局部高光细节与后备高光分支输入；不要当作整片粗糙度/金属度。
  A：内部墨线覆盖率=1-A，不能当透明度。只有 A 做特定屏幕足迹过滤。
_DetailMap / BGT_detail：RGB 乘法细节，TEXCOORD1；sRGB=0；1024×1024。
  albedo=base*lerp(1,detail,_DetailIntensity)。CoatExterior 的强度=0。
_OutlineMap / BGT_olm：RGB 墨色，sRGB=1；不是 Alpha 宽度贴图。
_RegionalMask / BGT_RegionalMask：R=皮肤，G=白袖；sRGB=0。
  脸和身体不只靠贴图区分，还需 Renderer MPB 的 _RegionalHead。
_FourMaterialSpecMask / BGT_SpecularClassMask：RGBA=头发/布料/皮肤/金属；sRGB=0。
  同时供高光、CleanShade 衣料、线条、边缘光读取；R 还被头发深度 Shader 用作 caster mask。
  A 是金属分类，不是透明通道；alphaIsTransparency=0。
_MainTex / BGT_decal（辅助贴花 Shader）：RGB 线性数据；sRGB=0。
  Blend DstColor SrcColor 形成 X2 Multiply，中性输入为 0.5；不能当普通透明贴图混合。

尺寸和导入设置以 texture_import_settings.json 为准。
主图集为 2048×2048；Detail/Decal 为 1024×1024。BGTW 武器组也为 1024×1024。
filterMode=1 表示 Bilinear；wrap=0 为 Repeat，1 为 Clamp；当前主体贴图 alphaIsTransparency 均为 0。
平台配置需先看 overridden。不能把未启用的平台保存值当作实际覆盖。
注意：武器 BGTW_ilm 的现存 sRGB=1，与主体 BGT_ilm 不一致。它属于当前未显示的武器预览资料，不能写成推荐的数据贴图设置；本次没有修正。

顶点输入：
  POSITION：现有蒙皮输出的位置；本包不提供模型或改网格操作。
  NORMAL：主要光照法线，转换至世界空间。
  COLOR.R：AO/明暗控制，lerp(1,vertex.r,_AOStrength)。
  TEXCOORD0：主图集 UV。
  TEXCOORD1：细节 UV（C# mesh.uv2）。
  TEXCOORD2：可选镜像 UV（C# mesh.uv3）；四主体材质当前 _UseMirroredUV=0。
  TANGENT.xyz：_UseSmoothOutline=1 时作为描边法线使用，不是“任意模型的标准切线都可代替法线”。
  当前四主体材质 _UseSmoothOutline=1。本次未审计网格顶点通道数值，不能证明换模型直接可用。

不提供任何原始或自制贴图像素。
换图集时应自己制作 R/G 分区和 RGBA 材质分类，关闭 sRGB，保持 Alpha 数据。
眼睛、胸前衣料和大腿高光含 2048 图集像素坐标，必须替换成新模型适用的域/遮罩。
不能仅缩放贴图尺寸便宣称完成移植。

04_actual_parameters

实际参数与生效关系

采样层级：Shader Properties 默认值 → .mat 保存值 → Renderer MPB / Shader 全局变量 → Shader 内部条件与覆盖顺序。
材质表中的 savedValue 不自动等于当前屏幕最终效果；不同层级分别查 CSV 和源码。
数值均为磁盘保存值或源码规则。本次不采集 Play 内存实例、不推算任意帧脸部坐标。

当前基础环境：Unity 2022.3.62f3c1；Built-in（Graphics 和各质量档 SRP 引用为空）；Linear。
主场景：Assets/Scenes/Bridget_ReferenceMatch.unity。
主相机：Perspective/FOV 54，位置(-0.113,0.903,1.822)，HDR/MSAA 开；精确四元数见 saved_scene_rendering.json。
方向光：Intensity 1.1，白色；旋转四元数(0.07075682,0.8591888,-0.12371239,0.49140963)。方向光照明由旋转决定。
Profile：MSAA=4、shadowDistance=20，并设 All/High。

四主体材质：Base_Imitate、BaseSecondary_Imitate、BodyBaseFlip_Imitate、CoatExterior_Imitate。
四者 CleanShade、FocusedShade、FocusedSpec、Palette、FourMaterialSpec、ThighLobe、ReferenceRim 均保存为 1。
四者 _ThighLobeStrength=0.16；_ReferenceRimWidth=0.24；_ReferenceRimStrength=0.5。
_OutlineWidth：Base/BaseSecondary/CoatExterior=0.8，BodyBaseFlip=0。
_DetailIntensity：Base/BaseSecondary/BodyBaseFlip=0.278，CoatExterior=0。
_EyeRefineEnabled / _FaceDiffuseRefine：Base/BaseSecondary=1，另外两者=0。
_HairFaceShadowStrength：Base/BaseSecondary=0，BodyBaseFlip/CoatExterior=0.75。
不能把最后一项写成“全体材质为零”或“只要为0.75就一定产生脸部阴影”；还需脸部区域门控和后续 CleanShade 覆盖。

运行时要点：
_RegionalEnabled：.mat=0；活动 GGSTRegionalShading 根据 strength 写入 MPB，已保存 strength=1。
_RegionalHead：body=0、standingHead=1；脸坐标来自现有头部 Transform 的只读矩阵。
_CharacterOriginWS / _CharacterHeight：Profile 根据 root 与启用时 bounds 写入，属于动态/初始化结果。
阴影脚本发布 _HairShadow* / _StageShadow* 深度纹理、矩阵和开关；Depends on Ready、Renderer 可见性及 draw flags。
保存的 drawHairCasters=1、drawStageCasters=1、suspendMaps=0；RFloat hair=1024、stage=2048（源码常量）。
hairRadius=0.28、hairRange=1.2、offset=0.08；stageRadius=2、stageRange=8。

Shader 的最终生效顺序：
颜色/Detail采样 → 后备明暗/分区 → 旧脸部修正与投脸 → Palette → CleanShade重建漫反射 → Focused局部漫反射 → 眼睛漫反射 → 基础/分材质高光 → Focused和ThighLobe替换 → ReferenceRim → 漫反射+环境+高光+rim → 内部线 → 原眼睛高光恢复 → 独立外轮廓Pass。
CleanShade 当前脸部亮暗依据世界空间 n.y；这是固定参考风格的美术近似，不是通用脸部SDF。
旧侧脸参数仍存在，不等于最终脸上必然有暗带。
_RimWidth 是旧后备路径，当前分类区域主要由 _ReferenceRimWidth 控制。
属性面板 _DebugMode 声明范围仍是0～24，但代码实际实现1～44；要查看更高编号需在练习副本通过脚本 SetFloat，不要修改原项目来迁就教程。

演示图与主工程的差别：
images/stages 是独立副本累计开关，不是主工程新增的配置。
它省略场景投影；相机投影 m00/m11 乘0.94；4K时描边像素宽度乘2以保持原1080p视觉比例。
主体材质保存表仍记录主工程0.8/0值，不能混写成4K副本临时1.6/0值。
images/project 是原工程历史图，保留其原构图/投影。

05_portability_and_gaps

移植依赖与资料缺口

1. 代码不是独立即用包。
GGSTRegionalShading 依赖 UEOriginalPersistentPresentation.groups 查找现有头部坐标。
GGSTGeometryShadowMaps 依赖 UEOriginalActionPlayer.nativeRendering 与 UEOriginalPersistentPresentation 取得现有 Renderer/骨盆。
这些动画/呈现桥接脚本未打包，避免将动画重建混入渲染教程。源码中保留相关类型用于说明原工程上下文。
教程后续应另写仅接受 Renderer、Transform、Light、Camera 引用的渲染适配示例，不能让读者复制这3个脚本后承诺零依赖编译。
BridgetImitateProfile 还有通过对象名 bgt_body.001 查找的回退逻辑，应在通用示例中改成显式引用。

2. 网格契约未重新检查。
平滑描边读取TANGENT.xyz，需使用已有满足契约的模型；不要为了教程改当前网格。
模型/骨骼/Bind Pose/动画均不随包分发。数据中的对象路径或骨骼数量只是记录，不是资源。

3. UV 专用常量。
胸前衣料、大腿亮块和眼睛使用当前图集的像素坐标，不能描述成任何角色可通用的公式。
拟写教程应同时说明“原工程精确复刻”与“换模型时重建区域”的区别。

4. 运行时证据边界。
当前MCP不可用，本次仅做磁盘只读检查；没有验证编辑器是否有未保存变化。
历史截图和播放报告均标为2026-10-20；当前428文件匹配旧快照，说明磁盘内容一致，不意味着今天重新播放验证。
Prefab引用解析并未重建完整场景实例。saved_scene_rendering.json保留未解析fileID；historical_scene_rendering.json可供交叉参考，不能伪造已解析结果。

5. 配图缺口。
已有9阶段图可说明累计变化；不是每个子参数独立实验。
腹部/腿部历史shade对比同时调整过高光，不可配“只改变阴影”的图注。
投影章缺少当前最终材质下同姿势单变量投影A/B。
眼睛章已有近景及分区诊断，缺少最终版本同条件局部开/关近景。
3个渲染脚本的独立通用适配器和全新工程复刻测试尚未完成。
